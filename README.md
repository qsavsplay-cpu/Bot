# ✨ TOXI Emoji Studio — Telegram-бот для анимированных эмодзи

Заменяет надпись в Lottie/TGS-эмодзи на твой текст (векторными буквами), красит всё эмодзи,
делает переливы, вставляет лого (SVG/PNG/JPG → вектор) и кладёт результат в твой пак **премиум-эмодзи**.

## Запуск на Railway
1. Залей папку в GitHub → Railway → *Deploy from GitHub repo*.
2. **Variables**:
   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от @BotFather |
   | `ADMIN_ID` | твой Telegram ID (можно несколько через запятую; узнать: напиши боту `/admin`) |
   | `DATA_DIR` | `/data` |
3. **Volume**: Service → *Settings → Volumes → Add Volume*, mount path `/data`.
   Без Volume шаблоны, которые ты добавляешь через админку, пропадут при следующем деплое.
4. Готово: бот стартует командой из `Procfile` (`worker: python bot.py`).

## Как пользоваться (для всех)
`/start` → **🚀 Создать эмодзи** — мастер из 4 шагов:
1. **Эмодзи** — GIF-каталог страницы с номерами и названиями; тапай номера (можно выбрать несколько).
2. **Тумблер 🔤 Текст / 🖼 Лого** — одно из двух. Текст: надпись заменяется, логотипы шаблона удаляются.
   Лого: надпись убирается, на её месте твоя картинка (SVG, PNG, JPG, WEBP, статичный стикер → автоматически в вектор).
3. **Покраска** — готовые темы одним нажатием: 🔴 красно-чёрная, ⚫ чёрно-красная, 🔵 сине-белая, 🟡 золото-чёрная и
   переливающиеся 🌈 радуга / 🔥 огонь / 🌊 океан / 💜 неон / 👑 золото. Красится всё: эмодзи, контур, текст.
   Тени и блики сохраняются. «Тонкая настройка» — цвета по частям, шрифт, размер, удаление слоёв.
4. **Ввод** — текст (каждая строка = отдельное эмодзи) или лого. Затем бот спрашивает, куда отправить:
   📩 в чат, 💎 в эмодзи-пак (кастомные эмодзи, для Premium) или 🎭 в стикер-пак.

* **🧩 Баннеры** из нескольких частей: текст растягивается на все части бесшовно, каждая часть — отдельное эмодзи.
  Админ собирает баннер из любых шаблонов: `🛠 → 🧩 Собрать баннер`.
* **Текст находится везде**: по имени (надпись, text, txt, trst, nick, HELL, logo…), по форме (ряд букв),
  а если в файле его нет вообще — бот добавит отдельный слой с текстом.

## Как добавить свои эмодзи
### Способ 1 — через бота (рекомендуется)
`/admin` → **➕ Добавить шаблон** → кидай `.json` или `.tgs` (можно пачкой). Название = подпись к файлу или имя файла.
Бот сам найдёт текст. Если нашёл не то: `📦 Шаблоны → шаблон → 🎯 Текстовый слой`. Кнопка **🧪 Тест** покажет результат.
### Способ 2 — через репозиторий
Положи файл в `builtin/` (`.tgs` или gzip-JSON) и добавь запись в `builtin/index.json`:
```json
"my1": {"title": "Мой эмодзи", "emoji": "🔥", "file": "my1.tgs", "order": 50,
        "settings": {"layer": "надпись", "skip": ["eye*"]}}
```
`settings.layer` — имя текстовой папки или `auto`. Новые записи подхватываются при старте, правки админа не затираются.

### Как подготовить эмодзи (Glaxnimate / LottieFiles / After Effects)
* Холст 512×512, до 3 секунд, итоговый `.tgs` ≤ 64 КБ (бот сам сожмёт округлением, если чуть больше).
* Надпись — **папка (группа) или слой из векторных букв**. Назови её `надпись` или `text` / `txt` / `trst` / `nick` / `HELL`…
  Если имя другое (`Group`, без имени) — бот узнаёт ряд из ≥3 букв **по форме** и предложит кандидатов.
* Внутри папки оставь заливку/контур/градиент — стиль сохранится, новый текст встанет в тот же центр и ту же ширину.
* Текстовые слои Lottie (ty 5) тоже понимает — превращает в вектор (TGS их не поддерживает).
* Лого-фигуры называй `logo` / `лого` — удалятся автоматически. Папка `LOGO` = место под твоё лого.
* Не удаляй у слоёв анимацию, которая нужна: старая анимация **внутри** надписи заменяется статичным текстом.

## Структура проекта
`bot.py` — Telegram, `ui.py` — экраны, `pipeline.py` — сборка, `render.py` + `preview.py` — отрисовка и GIF-превью, `detect.py` — поиск текста, `lottie_text.py` — буквы,
`colors.py` — цвета/переливы, `lottie_ops.py` — удаление/перекраска, `svgimport.py` / `trace.py` — лого,
`store.py` — шаблоны/пользователи, `builtin/` — встроенные эмодзи, `fonts/` — шрифты (с кириллицей).
